# CHANGELOG(backend)

## v1.4.0 (2026-10-20) 👍👎フィードバック(第1段階: 記録して測る)
- UI(index_beta.html): 聴くモードの下を2段に(上段=👍もっと上げて/👎下げて、下段=前へ/止める/次へ)。「これは不要」は廃止。👍=+1を記録するだけ、👎=-1を記録して次へ(次へ=既読にして進む。5秒の取り消し付き。降格はしない)。同じボタンの再押下で取り消し。聴くモードの「前へ」(ひとつ前の記事へ。今日の要点・保留の見出しには戻らない)。流すモード・保留の一覧にも👍👎。点数バッジの横に「あなた: N」。週次タブに「AIとのずれ」(30件未満は暫定)。端末キュー(FeedbackQueue)で通信失敗時は再送。
- DB(追加のみ): `post_feedback` 表(anon直接アクセス不可)、`feedback_set(url,value,surface)`、`feedback_list(days)`、`feedback_report(days)`。マイグレーション 20261020_008_feedback.sql。
- 採点・区分・閾値・関心プロファイルは変更しない(第2段階で別途設計)。
- テスト: SQL 101件、ui_core 232項目。ui_adminの⑬(答え合わせ回数)は今回の変更前から間欠的に失敗する(タイミング依存)。

## v1.3.0 (2026-10-17) 流すモードに「スキップ」
- UI(index_beta.html): 流すの操作を2段に。上段に全幅(76px)の「⏭スキップ(次へ)」、下段は前へ/止める/これ聴く。スキップは待たずに次へ進み、表示したカードを既読にする(既読なら何もしない・最後なら終了画面・一時停止中も可)。サーバー側の変更なし。
- テスト: ui_core 234項目、ui_admin 129項目がすべて合格(高さ667pxでの収まり・連打を含む)。

## v1.2.0 (2026-10-12) 聴くモードの画像表示・タイトルのリンク
- UI(index_beta.html): 聴くカードに画像を表示(1枚目を大きく=最大で画面の約40%、2枚目以降はサムネイルで切り替え)。画像のあるカードだけカード欄を約62%・操作ボタンを約38%にする(ボタンは52px以上)。画像タップはアプリ内の全画面表示(再生は続く)。タイトルはXの投稿へのリンク(タップで読み上げを中断=続きから再生可・既読にしない)。画像は https のみ、リンクは x.com/twitter.com のみ。読み込み失敗は枠ごと消す。次カードの1枚目を先読み。
- サーバー側の変更なし。テスト: ui_core 226項目、ui_admin 129項目。

## v1.1.0 (2026-10-09) 流すの操作追加・保留の一括既読
- UI(index_beta.html): 流すに「⏮前へ」「⏸止める/▶再開」を追加(戻ったカードは既読のまま。「これ聴く」で未読へ戻して昇格)。保留一覧に「✅保留をすべて既読にする」(確認あり・8秒の取り消し帯)。保留の見出しは、既読が混じるとき「保留 N件(未読M件)」。
- DB(追加のみ): `bulk_read_hold(p_dry)`(未読の保留を日付に関係なく全件既読。read_via=user)、`bulk_unread_hold(p_at)`(15分以内の一括分だけ未読へ戻す)。マイグレーション 20261009_007_bulk_hold.sql。
- テスト: SQL 89件、ui_core 211項目、ui_admin 129項目、単体255件がすべて合格。
