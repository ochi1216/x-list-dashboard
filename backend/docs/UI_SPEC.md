# index_beta.html の仕様(UI)
基本: 既存 `index.html` を複製して `index_beta.html` を作り、そこへ追加する。**一覧モードの既存動作(▶=全カード連続読み上げ、▲▼長押し=全カード連続無音移動、既読は飛ばす、投稿者グループ・時刻順、低価値フィルタ)は一切変えない**。ダークテーマ(bg #1a1a2e / accent #e94560)、絵文字はUnicode直書き。データはanonキーで`x_posts`を読み、既読化は`rpc/mark_read`(失敗時は従来のPATCH)。管理操作は`admin-api`(contract参照)。SupabaseのURLと公開キーは既存index.htmlにある。
## 画面
- 上部タブ: 今日 / 週次 / 費用 / 設定。再生中はタブを隠す。上部の帯は同時に1件(優先順: 取得遅れ>聴き残し>通知先未設定>暫定>未送信N件)。
- 今日タブ: 主ボタン「▶聴く(約N分)」1つ(N=聴くカードの読み上げ文字数÷(6.5×速度)を端末で再計算)。その日の最初だけ「今日の要点→聴くカード→保留上位5件の見出し」を連続再生。副ボタン「流す」「一覧」。内訳「聴く○件・約○分/流す○件/保留○件」(今日=02:00 JST起点、降格・失効を反映した現在値)。今日の要点カード(`digest_daily`、生成時刻表示、statusがpausedなら費用上限で停止中と表示)。「保留N件」から保留一覧(既読が混じる時は「保留 N件(未読M件)」)。一覧の上に「✅保留をすべて既読にする」: サーバーの未読保留(日付に関係なく全件)の件数を確認ダイアログに出し、実行後8秒は「取り消し」(15分以内の一括分だけ未読へ戻す)。通信失敗時は状態を変えず「通信できませんでした」。
- 聴くモード: 画面下半分を3つの大きなタップ領域(次へ=既読にして対象外 / 止める・再開 / これは不要=保留へ降格+既読、5秒の取り消し付き)。中断時「中断しました。続きから再生」の大ボタン。冒頭の重要度読み上げは5点と手動昇格のみ。聴き終えたら「上限で流すに回った4点以上が○件あります。続けますか」+「+10分聴く」。聴くが0件なら案内文。聴く=最後まで再生で既読(途中停止は未読)、「次へ」は既読。聴く順は 手動昇格→点数降順→新しい順。▶押下時に当日の聴く全件を端末に確保。
- 流すモード: 音声なしで1枚4秒の自動送り(変更可)、タップまたは「⏸止める/▶再開」で一時停止、「⏮前へ」でひとつ前のカードへ戻る(先頭では押せない。戻ったカードは既読のまま・時間は0から)、「これ聴く」で昇格(聴く待ちの先頭。既読なら未読へ戻す)。2秒以上表示で既読(mark_read via=flow)。
- カード表示: タイトル先頭に点数バッジ(5=濃色〜1=薄灰、未採点「–」)、直下に1行「種類(日本語)＋理由」。「暫定」は小さなチップ1つ(音声では読まない)。
- 設定タブ: 再生(速度・声の高音質/標準=localStorage、既定速度1.2を保存)、ログイン(セットアップコード+新パスフレーズ/パスフレーズ)、通知先の表示(コピー)とテスト通知、健康監視URL、関心プロファイル(読み上げ→承認/あとで/編集の大ボタン)、聴く量・閾値などの設定(config_get/set)、未送信操作のキュー表示。
- 週次タブ: 週次レポート本文(読み上げ可)、投稿者通信簿(低評価率・高評価率の区間つき。総数併記)、答え合わせ(20件×最大3回。実画面と同じ表示+▶で聴ける、大きな1〜5ボタン+区分4択(既定その他)、1タップごとに保存、残り件数・分、「今日はしない」で3日非表示)。今週の流れ(`digest_week`、7日分たまるまで「蓄積中 n/7」)。
- 費用タブ: 今月の実績(今日まで)と月末見込み、先月、過去の月ごとの推移(棒グラフ)、X系とTI系の内訳、モデル別の内訳、ガード段階、直近のエラー。
- 端末キュー: 管理操作(tier_set/label_submit)は操作ID付きでlocalStorageに積み、トークンが有れば即送信、失敗・未ログインなら溜めて後で再送(サーバー受理後にだけ削除)。ログイン画面を再生中に出さない(設定タブと細い帯のみ)。
